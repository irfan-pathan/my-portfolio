# My Portfolio

Static portfolio website built with HTML, CSS and Bootstrap 5.

## Run

Open `index.html` in a browser, or serve the folder with any static server, e.g.:

```
npx serve .
```

## Structure

- `index.html`, `about-us.html`, `resume.html`, `portfolio.html`, `contact-us.html`, `services.html` – pages
- `assets/css/main.css` – site styles
- `assets/js/main.js` – site scripts
- `assets/vendor/` – Bootstrap, AOS, Swiper, GLightbox, Isotope and other libraries
- `assets/img/` – images
